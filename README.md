# Coding Nights 3.0 — Night 1 🌙

Hands-on notebooks for **Big-O, HashMaps & Sets, Two Pointers and Sliding Windows**.

| Notebook | What's inside |
|---|---|
| `Night1_Part1_BigO_HashMaps.ipynb` | Big-O thinking, HashMaps & Sets, Frequency Counter, Two Sum |
| `Night1_Part2_Patterns.ipynb` | Two Pointers, Sliding Window, In-Place tricks, the 5-step interview method |

Start with **Part 1**, then move on to **Part 2**. Both end with practice problems and hidden answer keys.

---

## 1. Get the code

You need [Python 3](https://www.python.org/downloads/) and [Git](https://git-scm.com/downloads) installed.

```bash
git clone https://github.com/NTUWIT/Coding-Nights-Practice-Notebooks.git
cd Coding-Nights-Practice-Notebooks
```

## 2. Install what you need

Create a virtual environment (a private space for this project's packages), then install the packages:

**macOS / Linux**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Windows**
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 3. Open the notebooks

```bash
jupyter notebook
```

A browser tab opens. Click **`Night1_Part1_BigO_HashMaps.ipynb`** to begin.

> Next time, you only need to `cd` into the folder, activate the environment (step 2, second line) and run `jupyter notebook`.

---

## How to work through a notebook

- Run the **setup cell** at the top first.
- Press **Shift + Enter** to run a cell and move to the next one.
- Before running a **trace** cell, guess what it will print. Then check!
- In the practice section, replace `pass` with your code, run it, then run the **check cell** below it to see ✅ or ❌.
- Stuck? Click **Reveal answer key**. Try for a while first. That's where the learning happens.

**No install?** You can also upload the notebooks to [Google Colab](https://colab.research.google.com) and run them there.
